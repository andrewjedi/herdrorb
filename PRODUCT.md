# Product

herdrorb is an independent, open-source macOS companion for Herdr. Its users
manage Codex and Claude Code sessions on their own local and remote Macs.

Keep conversations and interactive terminals accessible from a compact
menu-bar panel and floating orb. Preserve the quiet observatory artwork,
lavender selection accents, and readable dark terminal appearance.

Give conversations the space. Make the selected machine, session, and view
clear. Surface setup and connection errors with an actionable recovery path.
Preserve running sessions and drafts. Keep secondary actions discoverable
without oversized headers or redundant status labels.

Support labeled native controls, keyboard use, adequate contrast, and Reduce
Motion. Treat user data as private; diagnostics should be safe to share by
default. Avoid telemetry and credentials in the application.
